ANDROID GAME

BoardDuel

オセロ・将棋・ONO・七煌麻雀を一つのアプリで。ひとりでも、友達とオンラインでも。

Latest Ver. 10.21 Android 8.0以上 無料
インストール・アップデート

APKをダウンロードして、Androidの確認画面からインストールしてください。

Ver. 10.21 の更新内容

七煌麻雀のオンライン対戦を安定化。バックグラウンドからの復帰と、正常な操作中に確認待ち警告が出る問題を修正しました
終局後の再接続・CPU代行表示と最後の退出を修正。不正な設定を拒否した際、一部だけ変更されないようにしました
役ナビの不足・条件外の牌と固定面子の判定を改善。長い名前や、属性に対応する演出牌の表示も調整しました。ナビの作りやすさ・途中の点数は目安です
オセロ・将棋・ONOと麻雀の基本ルールは維持。一緒に遊ぶ方も最新版へ更新してください。オンライン麻雀は処理担当端末を信頼する友人間の対戦方式です

インストール方法

  1. 上のボタンからAPKを保存
  2. ダウンロードしたAPKを開く
  3. Androidの確認画面でインストール
  4. 「BoardDuel」を起動

遊べるモード

オセロ
色を一覧から選べる、ひとり・ローカル・オンライン対戦
将棋
ルール・補助表示・待ったに対応した各種対戦
ONO
CPU・オンライン対戦、独自カード、扇型手札と勝ち抜け観戦
七煌麻雀
オリジナル牌、役ナビ、CPU・最大4人オンライン、操作チュートリアル
更新時も同じボタンから最新版をダウンロードできます。
Androidの設定によっては、ブラウザからのアプリのインストール許可が必要です。
