ANDROID GAME

BoardDuel

オセロ・将棋・カードゲームONOを一つのアプリで。CPU対戦に加えて、離れた場所の相手ともオンラインで楽しめます。

Latest Ver. 9.0 Android 8.0以上 無料
インストール・アップデート

APKをダウンロードして、Androidの確認画面からインストールしてください。

Ver. 9.0 の更新内容

新ゲームONOを追加。5色・150枚のオリジナルカードで遊べます
1人＋CPU1〜3人、または最大4人のオンライン対戦に対応しました
部屋を作ってから人数・CPU難易度・特殊カード・制限時間などを設定できます
同数字の連続出し、＋2／＋4の累積、透視・手札交換・ドパガキクラッシャーを搭載しました
残り1枚でドパガキ！宣言を忘れると足し算チャレンジ。数字1〜7がそろう「ことバースト」でも勝利できます
開始前から最大8人が観戦でき、全手札と山札の順番を確認できます
再戦・ルームに戻る・退出の選択を表示。途中退出時はCPUが引き継ぎます
BGMと効果音を個別に設定でき、勝敗演出やタップ・スワイプ操作にも対応しました
既存のオセロ・将棋・育成AIと保存データは、そのまま引き継いで更新できます

インストール方法

  1. 上のボタンからAPKを保存
  2. ダウンロードしたAPKを開く
  3. Androidの確認画面でインストール
  4. 「BoardDuel」を起動

遊べるモード

オセロ
色を一覧から選べる、ひとり・ローカル・オンライン対戦
将棋
ルール・補助表示・待ったに対応した各種対戦
更新時も同じボタンから最新版をダウンロードできます。
Androidの設定によっては、ブラウザからのアプリのインストール許可が必要です。
