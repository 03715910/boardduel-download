ANDROID GAME

BoardDuel

オセロ、将棋、すごろくを一つのアプリで。1台での対戦に加えて、離れた場所の相手ともオンラインで楽しめます。

Latest Ver. 5.6 Android 8.0以上 無料
インストール・アップデート

APKをダウンロードして、Androidの確認画面からインストールしてください。

Ver. 5.6 の更新内容

オセロのオンライン対戦に、許可制の「一手戻す」を追加
申請中は両端末の盤面操作を止め、二重操作を防止
相手が承認した場合だけ、直前の盤面と手番へ安全に復元

インストール方法

  1. 上のボタンからAPKを保存
  2. ダウンロードしたAPKを開く
  3. Androidの確認画面でインストール
  4. 「BoardDuel」を起動

遊べるモード

オセロ
色を一覧から選べる、ひとり・ローカル・オンライン対戦
将棋
ルール・補助表示・待ったに対応した各種対戦
すごろく
2〜4人オンライン・待機室での色変更・CPU参加
更新時も同じボタンから最新版をダウンロードできます。
Androidの設定によっては、ブラウザからのアプリのインストール許可が必要です。
