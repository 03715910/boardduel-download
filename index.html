ANDROID GAME

BoardDuel

オセロ・将棋・カードゲームONOを一つのアプリで。CPU対戦に加えて、離れた場所の相手ともオンラインで楽しめます。

Latest Ver. 9.11 Android 8.0以上 無料
インストール・アップデート

APKをダウンロードして、Androidの確認画面からインストールしてください。

Ver. 9.11 の更新内容

PEEKの細長い表示を修正。通常と同じ比率・絵柄のカードを、重ねず左右スクロールで確認できます
手札は1タップで選択、ダブルタップで使用。「このカードを出す」ボタンも残しています
指でなぞると触れたカードを拡大し、離すと通常表示へ戻ります。なぞるだけではカードは出ません
先攻サイコロは各人の出目と先攻・同率を表示。全員が「次へ」で確認するまで進みません。同率者だけ再抽選します
カード図鑑・8枚ずつの手札ページ切替・順位付きの対局継続を維持。カード効果・CPU仕様・勝利条件は変えていません
ONOオンラインは全員Ver.9.11へ更新して新しい部屋を作ってください。旧部屋からの退出も可能です
既存のオセロ・将棋・育成AIと保存データは、そのまま引き継いで更新できます

インストール方法

  1. 上のボタンからAPKを保存
  2. ダウンロードしたAPKを開く
  3. Androidの確認画面でインストール
  4. 「BoardDuel」を起動

遊べるモード

オセロ
色を一覧から選べる、ひとり・ローカル・オンライン対戦
将棋
ルール・補助表示・待ったに対応した各種対戦
更新時も同じボタンから最新版をダウンロードできます。
Androidの設定によっては、ブラウザからのアプリのインストール許可が必要です。
